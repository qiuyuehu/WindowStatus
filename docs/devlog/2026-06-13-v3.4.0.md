### 踩坑记录

1. eraseRect() 会用 widget 背景色填充（默认白色），不是透明。想透明用 WA_TranslucentBackground
2. 给 QTabBar 加 stylesheet 会干扰自绘 paintEvent，用 setDocumentMode(True) 替代
3. QGridLayout+QPainter 分隔线必须和 grid 列边界对齐，不能用 widget 宽度的 1/3
4. 有 demo 还要逐像素对照，不要凭感觉改代码
